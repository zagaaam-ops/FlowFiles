# FlowFiles

FlowFiles is a modern cross-platform file manager built with Flutter.

## Vision

Create a fast, clean and powerful file explorer that works consistently across:

- Windows
- Android
- iOS
- Tablets

using a single Flutter codebase.

---

## Current Features

### Navigation

- Browse folders
- Home
- Up
- Breadcrumb navigation
- Refresh

### Explorer

- Search
- Sorting
- Multi-selection

### File Operations

- Copy
- Cut
- Paste
- Rename
- Delete
- Create Folder
- Create Empty File
