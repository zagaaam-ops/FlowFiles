# Vision

FlowFiles aims to become a modern, fast, intelligent, cross-platform file manager focused on productivity, cloud integration, AI assistance, and enterprise-grade usability.

---

# Development Workflow

For every feature:

1. Architecture Review
2. Full File Replacement
3. Terminal Deployment
4. Dart Format
5. Flutter Analyze
6. Git Commit
7. Git Push

No partial edits.

No manual code patching.

Every change must compile successfully before moving to the next task.

---

# Coding Standards

- Clean Architecture
- SOLID Principles
- Feature-first folder structure
- Controller-based state management
- Production-quality code only
- No temporary hacks
- No commented dead code
