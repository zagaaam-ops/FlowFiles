# FlowFiles Roadmap

Version: Draft 0.1

---

# Vision

Build the fastest open-source file organization application available for desktop and mobile platforms.

The project focuses on reducing unnecessary navigation and repetitive actions when organizing large numbers of files.

---

# Development Principles

- Open Source (MIT License)
- Cross-platform
- Clean Architecture
- Performance First
- Privacy First
- Offline First
- Community Driven
